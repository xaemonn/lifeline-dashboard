# Opening the Lifeline dashboard in Power BI Desktop

The dashboard is saved as a **Power BI Project (PBIP)**: plain-text files that Power BI Desktop opens like a
`.pbix`. It was generated by `scripts/04_build_powerbi.py` and checked by `scripts/05_check_powerbi.py`
(all files valid against Microsoft's published PBIR schemas; every DAX and visual field reference resolves).

## Steps

1. Install **Power BI Desktop** (free, Microsoft Store). Any 2026 release works.
2. Double-click `powerbi/LifelineDashboard.pbip`.
3. The model opens without data the first time. Click **Home > Refresh** (about 10 seconds).
   - If asked about privacy levels for the CSV files, choose **Ignore privacy levels** (local files only).
4. Check the KPI cards against the values below. If they match, the model loaded correctly.
5. To hand in a single file: **File > Save as**, choose **Power BI file (*.pbix)**.

## Pages

1. **Executive overview**: value by year, late rate by year split by fulfilment route, product mix, top countries, late rate by mode
2. **Delivery performance**: mode x route matrix, delivery-status distribution, late rate by country and vendor (red/amber/green)
3. **Freight and cost**: weight vs freight by country, freight per kg by mode, freight % by region, how freight was recorded
4. **Vendor and product**: direct-drop vendor Pareto, vendor scorecard, molecules by value
5. **Country risk and segments**: K-means segments, late rate by segment, association rules, country detail

Year, Region, Shipment mode and Product group slicers are synced across all pages.

## Troubleshooting

- **"Couldn't find file ... fact_shipment.csv"**: the project folder moved. Either re-run
  `python scripts/04_build_powerbi.py`, or in Power BI go to **Transform data > Manage parameters > ProjectFolder** and
  set the new folder path (it must end with `\`).
- **Data changed** (re-ran scripts 01 or 03): just click **Refresh**.
- **A visual shows an error or looks wrong**: note the page and visual title, then fix it in Desktop or ask for the
  generator to be adjusted. Editing in Desktop and saving keeps everything in the same PBIP folder.
